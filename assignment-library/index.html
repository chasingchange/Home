Bring assignments in

Pulls every row of a Notion database into the library — the title column, Core, Category, Tags, Due in days, and each page's body as the instructions. Re-running updates the rows it pulled before instead of duplicating them.

One-time setup
  1. In Notion: Settings → Connections → Develop or manage integrations → New integration. Copy its secret.
  2. Open your assignments database → ••• → Connections → add that integration.
  3. Deploy the sync function: supabase functions deploy notion-assignments
  4. Save the secret: supabase secrets set NOTION_TOKEN=secret_…

Only databases shared with your Notion integration show up.

In Notion, open the database → ••• → Export → Markdown & CSV (include subpages), then drop the .zip here. Loose .csv / .md / .txt files and this library's JSON backup work too.

Paste one or many assignments. Start each with a # Title line, then Code: B.1 (or Core: / Week:) and the sections — RELEVANCE |, OUTCOME |, TO DO |, IMPLEMENTATION |, ALTERNATIVE |, EXAMPLES | (or ## Relevance headings). Rows copied from a spreadsheet with a header row, CSV and JSON work too.

Paste a link: a Notion page or database (shared with your integration), a Google Doc or Sheet shared as “anyone with the link”, or any public .csv / .md / .txt / .json file or web page.
